# Woubshet Behutiye — academic website redesign

This is a responsive, accessible static-site redesign for GitHub Pages.

## Deployment

Copy the files into the root of the `habeshwoub.github.io` repository, preserving the folder structure, then commit and push to the repository's publishing branch.

The redesigned pages retain the existing public paths:

- `/index.html`
- `/nav/about.html`
- `/nav/Publications.html`
- `/nav/projects.html`
- `/nav/Teaching.html`
- `/nav/cn.html`

Before publishing, verify the current appointment text, publication metadata, external academic-profile URLs, and any additional 2025–2026 publications.
